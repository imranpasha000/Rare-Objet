# Just A Click - Home Furnishing Website

A modern, responsive website for Just A Click, a complete home furnishing partner offering end-to-end solutions from design to global delivery.

## 🚀 Features

- **Modern Design**: Clean, professional layout with Tailwind CSS
- **Responsive**: Fully responsive design that works on all devices
- **Interactive**: Smooth animations and hover effects
- **Multi-page**: Dedicated pages for different sections
- **Accessibility**: Built with accessibility best practices

## 📁 Project Structure

```
├── index.html          # Homepage with hero section and overview
├── services.html       # Services page with detailed service offerings
├── products.html       # Products page with product categories
├── why-we-exist.html   # Why We Exist page with company values
├── portfolio.html      # Portfolio page with project showcase
├── styles.css          # Custom CSS styles and animations
├── script.js           # JavaScript functionality
└── README.md           # Project documentation
```
